# More Ores

**More Ores** is a Minecraft mod that adds a wide variety of new content to the game.  
Not only does it introduce **new ores**, but it also expands gameplay with

- ⚒️ New tools & special tool types  
- 🌳 New trees & unique wood types  
- ⛏️ Extra resources and crafting recipes  
- …and much more to discover!  

This mod is designed to give players more progression, creativity, and exploration opportunities, while staying true to the Minecraft feel.
